# จินตคณิต · แบบฝึกหัด

เว็บแอป (PWA) ฝึกจินตคณิตบนแท็บเล็ต ตามบทเรียนสูตร 1–34 สร้างโจทย์ใหม่ทุกครั้งด้วยการจำลองลูกคิด จับเวลาและเก็บสถิติในเครื่อง

เปิดใช้: https://pisanurits.github.io/jintakanit/

- `index.html` ไฟล์แอปรวม (สร้างจาก `src/` ด้วย `src/build.sh`)
- `src/engine.js` ลูกคิดจำลอง + ตัวสร้างโจทย์ · `src/test_engine.js` ทดสอบ (`node src/test_engine.js`)
